# Google Calendar Integration Plan

## Overview

Add the ability to publish EV charging recommendations to a shared Google Calendar, allowing you and your wife to see optimal charging windows directly in your calendar apps.

## Architecture Decision: Two Approaches

### Option A: Service Account with Shared Calendar (Recommended)

**How it works:**

- Create a dedicated Google Calendar for EV charging
- Use a Google Cloud service account for server-side automation
- Share the calendar with both you and your wife
- Events appear automatically - no manual interaction needed

**Pros:**

- Fully automated (no browser login required)
- Works with launchd scheduling
- Calendar can be shared with anyone
- Events sync to all devices automatically

**Cons:**

- Requires Google Cloud Console setup (one-time)
- Service account credentials stored locally

### Option B: OAuth2 with Personal Calendar

**How it works:**

- Use OAuth2 to authenticate as yourself
- Add events to your primary calendar
- Invite your wife as an attendee

**Pros:**

- Uses your existing calendar
- Simpler credential management

**Cons:**

- Requires initial browser-based login
- Token refresh can fail without interaction
- Less suitable for automated scripts

**Recommendation:** Option A (Service Account) - better for unattended automation.

## Implementation Plan

### Phase 1: Google Cloud Setup (Manual - One Time)

1. **Create Google Cloud Project**
   - Go to https://console.cloud.google.com
   - Create new project: "EV Charging Optimizer"
   - Enable Google Calendar API

2. **Create Service Account**
   - IAM & Admin → Service Accounts → Create
   - Name: "ev-charging-bot"
   - Download JSON credentials file
   - Store as `config/google_credentials.json`

3. **Create Shared Calendar**
   - In Google Calendar, create new calendar: "EV Charging Schedule"
   - Share with service account email (from JSON file)
   - Share with your wife's email
   - Note the Calendar ID (looks like: `abc123@group.calendar.google.com`)

4. **Update Configuration**
   - Add calendar settings to `config/config.yaml`
   - Add credentials path to `.env`

### Phase 2: Calendar Client Module

**New file:** `src/modules/google_calendar.py`

```python
"""Google Calendar Integration

Publishes EV charging recommendations as calendar events
for easy sharing between household members.
"""

from google.oauth2 import service_account
from googleapiclient.discovery import build
from datetime import datetime, timedelta
from typing import Dict, Any, Optional, List
from dataclasses import dataclass
import logging

@dataclass
class CalendarEvent:
    """Represents an EV charging calendar event"""
    title: str
    start: datetime
    end: datetime
    description: str
    color_id: str  # Google Calendar color (1-11)

class GoogleCalendarClient:
    """Client for publishing charging windows to Google Calendar"""

    SCOPES = ['https://www.googleapis.com/auth/calendar']

    # Color mapping for ratings
    RATING_COLORS = {
        'EXCELLENT': '10',  # Green
        'GOOD': '9',        # Blue
        'AVERAGE': '5',     # Yellow
        'POOR': '11',       # Red
    }

    def __init__(self, credentials_path: str, calendar_id: str):
        """Initialize with service account credentials"""

    def create_charging_event(self, window: ChargingWindow,
                              config: Dict) -> str:
        """Create calendar event for charging window"""

    def update_or_create_event(self, window: ChargingWindow,
                               config: Dict) -> str:
        """Update existing event or create new one (idempotent)"""

    def delete_old_events(self, before_date: datetime) -> int:
        """Clean up past events older than specified date"""

    def create_multi_day_events(self, plan: MultiDayPlan,
                                config: Dict) -> List[str]:
        """Create events for entire multi-day plan"""
```

if config.get('google_calendar', {}).get('enabled', False):

        calendar_client = GoogleCalendarClient(
            credentials_path=config['google_calendar']['credentials_path'],

## Setup Instructions (For User)

### Step 1: Google Cloud Console

1. Go to https://console.cloud.google.com
2. Create project → "EV Charging Optimizer"
3. APIs & Services → Enable APIs → Search "Google Calendar API" → Enable
4. APIs & Services → Credentials → Create Credentials → Service Account
5. Name: "ev-charging-bot", click Create
6. Skip role assignment (not needed for calendar)
7. Click on the service account → Keys → Add Key → JSON
8. Save as `config/google_credentials.json`

### Step 2: Create Shared Calendar

1. Open Google Calendar (calendar.google.com)
2. Left sidebar → "+" next to "Other calendars" → Create new calendar
3. Name: "EV Charging Schedule"
4. Create calendar
5. Click on the new calendar → Settings and sharing
6. Copy the Calendar ID (ends with @group.calendar.google.com)
7. Under "Share with specific people", add:
   - The service account email (from credentials JSON, looks like `ev-charging-bot@project-id.iam.gserviceaccount.com`)
   - Your wife's email
8. Give both "Make changes to events" permission

### Step 3: Configure

1. Add calendar ID to `config/config.yaml`:
   ```yaml
   google_calendar:
     enabled: true
     calendar_id: "your-id@group.calendar.google.com"
   ```

2. Test the integration:
   ```bash
   python src/scripts/sync_calendar.py --test
   ```
